# 云裁 BalloonFit · 热气球裁片充气验证

一个纯 TypeScript + WebGPU 的热气球定制造型验证工作台。设计师在平面纵向裁片上绘图后，系统把 **20 条裁片 × 每条 60 块布** 缝合为结构化膜网格，在 WebGPU 计算着色器中按内外压差、布料拉伸刚度和加强带刚度计算充气形状、带间鼓包与应变，并直接用 WebGPU 渲染草地冷充、点火热充和直立过程。

## 启动

```bash
npm install
npm run dev
```

打开终端输出的本地地址，建议使用最新版 Chrome / Edge。需要可用的 WebGPU 适配器；页面右上角会显示检测状态。

生产构建：

```bash
npm run build
npm run preview
```

## 四个工作页

1. **裁片图案**
   - 20 条纵向裁片可选，每条 60 个布块站位。
   - 画笔、直线、矩形、橡皮、横排/竖排文字、星形标志。
   - 四套自编图案：`凌云竞速条纹`、`庆典红金福球`、`几何广告菱格`、`熊猫团团定制`。
   - 3840×2160 的裁片 Atlas 直接作为 WebGPU 纹理，支持把当前裁片铺满全部 20 条。

2. **充气形状**
   - 三种自编球形：经典水滴自然球、宽体庆典球、高瘦探索球。
   - 可调压差 `Δp`、布料拉伸刚度 `E`、加强带刚度。
   - 应力/应变热力图、加强带、自动环绕和地面/侧面/正面/空中机位。
   - 一键回读 GPU 位置缓冲，将经线轮廓与理论自然轮廓比较。

3. **冷充立起**
   - 从平铺折叠在草地上的裁片开始，经历风机冷充、卧式饱满、点火热充、抬头和直立。
   - 时间轴可拖动、播放/暂停，支持 1×/2×/4×。
   - 相机目标随平躺到直立过程平滑转移。

4. **图案变形检查**
   - 黄色线为 GPU 回读的图案直线变形，青色线为两加强带间弦线，粉色虚线为膜力预测。
   - 同时给出多个布块的实测矢高、预测矢高、偏差和应变。
   - 可按裁片、布块定位，点击表格行切换检测位置。

## 网格规模

```text
纵向裁片              20
每条布块              60
每裁片横向细分        12
每布块纵向细分        4
环向重复列            20 × (12 + 1) = 260
纵向环数              60 × 4 + 1 = 241
GPU 顶点              62,660
渲染三角形            115,200
计算通道              形状求解 + 法线求解
```

## 计算模型

形状和法线均在 WGSL compute shader 中更新：`src/gpu/shaders.ts`。

相邻加强带在半径 `R` 处的弦跨距为：

```text
L = 2R sin(π / 20)
```

带间布片按抛物线膜条近似。由几何伸长和胡克定律：

```text
ε = 8h² / (3L²)
T = Eε
p = T · 8h / L²
```

得到鼓包高度：

```text
h = (3pL⁴ / 64E)^(1/3)
```

经线加强带使用远高于布片的刚度，因此应力显示最大但弹性伸长很小。理论轮廓表由 `src/core/profiles.ts` 生成，GPU 中加强带站位严格采样同一张表；检查页回读实际位置后再做归一化偏差评定。

## 已验证指标

在 Windows 11 + Chrome 158 + AMD Radeon 780M 上用 Playwright/硬件 WebGPU 实测：

- 经典自然球 GPU 回读轮廓最大偏差：**0.41%**，RMS **0.39%**，满足 ≤ 2%。
- 第 30 块布检测线实测矢高 / 预测矢高：**204 mm / 204 mm**，偏差显示 **0.0%**。
- 中点应变 GPU 回读 / 公式预测：**0.69% / 0.69%**。
- 强制 3840×2160 缓冲的 5 秒压测：平均约 **127 FPS**、最低约 **92 FPS**。
- 冷充页强制 4K 时统计约 **108 FPS**。

不同 GPU/驱动会有差异；各页均有实时 FPS、帧时间、绘图缓冲分辨率和“5 秒 4K 压测”按钮，可在目标机器上复核。

## 浏览器冒烟脚本

```bash
# 终端 A
npm run build
npm run preview -- --port 4176

# 终端 B（Windows 桌面环境，硬件 WebGPU）
HEADFUL=1 SMOKE_URL=http://127.0.0.1:4176/ node scripts/smoke-webgpu.mjs
```

脚本会打开四个页面、等待 WGSL 编译和 GPU 回读，并输出指标与截图。无显示环境中的 headless SwiftShader 可能不提供 WebGPU adapter，因此性能验收应使用硬件 GPU 会话。
